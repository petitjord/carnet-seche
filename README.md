# Carnet Sèche

Application mobile (PWA) de suivi de perte de gras : profil et besoins caloriques avec déficit, macros, pesées hebdomadaires avec courbe, journal de séances (exercices, charges, séries, répétitions), séances types et message de motivation du jour.

Aucun serveur : les données restent sur le téléphone. Une sauvegarde/restauration est disponible dans l'onglet Profil.

Installation sur iPhone : ouvrir le site GitHub Pages dans Safari, Partager, puis « Sur l'écran d'accueil ».
